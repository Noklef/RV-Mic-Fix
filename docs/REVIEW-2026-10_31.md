## Must fix

### 1. MIC-DIAG crash on first tick — `src/Main.cpp:358` (checked)

The null-check change lets `voiceChatDevice` reach `GetControllerUniqueNetId` for the first time.
`ue::Call` only zero-fills its parameter buffer (`src/Reflection.hpp:117`). It never calls `InitializeValue`.
The native thunk writes the `FUniqueNetIdRepl` result with `operator=`, so the vptr stays null.
`idResult->property->DestroyValue(...)` then calls the virtual destructor through a null vtable.
That is an access violation (SEH), and `catch (const std::exception&)` does not catch it. The game crashes about 1 s after load.

Fix: call `InitializeValue` on parameter slots before `invoke()` (best done in `Call`).

## Should fix

### 2. Slider step is too small for gamepad or keyboard — `src/Widgets.cpp:819`

`StepSize = 5.0 / Prefs::MaxPercent` (0.025) is correct for the normalized drag path.
